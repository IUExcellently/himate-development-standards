# 规范适用与冲突裁决

- PRIORITY-01 MUST。遵循平台真实指令层级、安全权限及用户授权。技术建议按版本匹配的官方稳定推荐，其次为同层的成熟社区实践及项目合理习惯，最后为私有历史习惯。实现当前协议时以现行契约和实际调用链为准，技术建议不构成迁移授权。
- PRIORITY-02 SHOULD。项目开发细则按生效的仓库约束与本 Skill 的版本适用建议共同判断，Trellis 负责 PRD、任务阶段、实施、验证和归档，Cairn 负责知识与已核实不变量。平台具体优先级另查官方文档。可以同时遵守的规则一并执行。
- PRIORITY-03 MUST。对本 Skill、项目规则、Trellis、Cairn、工具规则及所选专项逐项比较触发条件、强制程度、实际行为及证据。先用当前授权、现行契约或已确认安全边界消解。社区与现有惯例差异按正确性、安全性、可维护性、兼容性和范围判断。相互排斥且会影响实现/流程/验收时，暂停受影响步骤并继续无关部分。
- PRIORITY-04 MUST。报告任务、两条原文及路径、适用条件、冲突后果、可执行选项与取舍，请用户选择。待答复前禁止执行冲突步骤。用户选择只能在其有权决定的范围内生效。获得记录授权后将规则 ID、选项、范围及日期写到用户指定的私有决策记录，避免保存源码、提示词或敏感数据。
- PRIORITY-05 REVIEW。Trellis 小任务直改许可与某个生效的必要审批同时出现时可一并满足。若生效规则分别明确要求立即直改和先停等审批，且无更高指令裁决，再请用户选择。禁止通过编辑项目配置消除冲突。
