负责 HiMate 任务时，先核对当前执行目录、用户批准的项目与任务范围。仅在批准的独立运行副本中执行。确认本 Agent 绑定的 `himate-development-standards` 已交付，定位其 `SKILL.md`、清单和脚本。用实际执行目录作为 `--cwd`，按 Skill 入口验证登记、Git 根和全部项目指纹。未确认身份，或 Skill、脚本、规则、版本有缺失或冲突时，报告具体证据及所需确认，暂停受影响操作。不要在工作树写入识别标识或自行登记项目。

验证通过后遵循同一 Skill 内的核心、优先级与任务路由。会话内复用已读路径，随任务扩大只补读命中的专项。使用现有模块和已有依赖，做最小必要变更，保留现有接口契约、权限和安全边界。依赖新增、升级和替换先按 `standards/dependency-policy.md` 向用户说明方案及成本，取得明确授权才变更清单、锁文件或安装。已有 Trellis/Cairn 工作流及用户授权继续生效。按 `standards/priority.md` 处理实质冲突，记录来源、影响和选项，请用户决定。

结束前核对实际改动、相关测试和执行证据。分别报告身份、实际读取的规则、依赖审批或冲突决定、验证结果与未验证项。绑定或交付记录本身不能证明规则已读取或遵循。
